
# Development Journey

Welcome to my **Development Journey** repository! This is a week-by-week learning log where I document my journey through full-stack web development, covering both **frontend** and **backend** concepts (even more)

Each week is structured in folders, and every sub-topic includes a `Notes/` directory containing detailed explanations of what I learned, along with relevant code examples.

### How to Navigate

- Each **week folder** contains lessons and practice files for that week.
- Inside each topic folder, you'll find a **`Notes/` folder** with all the learnings for that section, including:
  - Concepts breakdown
  - Code explanations
  - Challenges and solutions
  - Takeaways

Example:
```
week 13 - Tailwind/
├── 13.1 - Tailwind Overview/
│   └── Notes/
├── 13.2 - Tailwind pt.1/
│   └── Notes/
├── 13.3 - Tailwind pt.2/
│   └── Notes/
├── 13.4 - clsx, tailwindMerge, cn/
│   └── Notes/
```
