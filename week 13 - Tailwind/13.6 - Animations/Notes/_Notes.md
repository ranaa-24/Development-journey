# Tailwind Animation and Libraries

[Tailwind animation Docs](https://tailwindcss.com/docs/animation)
[Tailwind animation](https://www.youtube.com/watch?v=O3XfiFhhTSA)
[Tailwind CSS Motion](https://youtu.be/cIjkDmbsHPw?si=bHL0m1E9cO_IyxDR)

Here are a few popular Tailwind animation libraries:

1. [Tailwind CSS Animate](https://github.com/tailwindlabs/tailwindcss-animate) - A plugin that provides a set of predefined animations for Tailwind CSS.
2. [Motion One](https://motion.dev/) - A modern animation library that works seamlessly with Tailwind CSS.
3. [Framer Motion](https://www.framer.com/motion/) - A powerful animation library that can be integrated with Tailwind for advanced animations.
4. [LottieFiles](https://lottiefiles.com/) - A library for adding Lottie animations, which can be styled with Tailwind.
5. [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/) - A library for scroll animations that pairs well with Tailwind.

These libraries can enhance your Tailwind projects with smooth and customizable animations.
